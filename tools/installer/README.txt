SpireMeter - live damage meter for Slay the Spire 2

Install or update
  1. Close the game.
  2. Double-click install.cmd.
  3. Start the game. If it asks whether to load mods, say yes.

By hand
  Copy the SpireMeter folder into the game's mods folder.
  (In Steam: right-click the game > Manage > Browse local files.)

Uninstall
  Delete the SpireMeter folder from the game's mods folder.
